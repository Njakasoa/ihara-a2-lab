# Protocole d'expériences

M1 doit être contrôlé avant une recherche M2. Chaque expérience enregistre ses
entrées, son domaine exact, le théorème utilisé, les règles d'élagage, le nombre
de configurations, les échecs et les résultats. Une optimisation utilise la
borne finale prouvable, jamais N/g comme score de substitution.

Le premier domaine prévu utilise les lieux réellement énumérés du corps k343.
Les places de même degré sont échangeables pour le seul théorème qui dépend
des degrés et de bornes locales ; elles ne le sont pas pour un calcul exact de
groupe de rayon ou de décomposition supplémentaire.

Les branches avec conducteurs non uniformes conservent les contraintes de
rang et le coût de ramification exacts du théorème choisi. Une inégalité ratée
signifie « critère insuffisant », jamais « tour finie ».
